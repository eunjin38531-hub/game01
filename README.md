# game01 — 트롤 투수

공만 치면 되는데... 투수가 정상이 아니다.
타이밍 맞춰 스윙해서 말도 안 되는 마구를 홈런으로 받아치는 브라우저 야구 게임.

- 사이트: https://eunjin38531-hub.github.io/game01/
- `main` 브랜치에 push하면 GitHub Pages에 자동 반영됩니다.

## 조작

- PC: 스페이스바(또는 J) 스윙, Esc 일시정지, Enter 버튼 선택
- 모바일: 화면 탭으로 스윙

## 규칙

- 스테이지마다 공 10개, 정해진 개수의 홈런을 치면 클리어
- 공이 홈플레이트에 닿는 순간과 스윙 타이밍의 차이로 판정
  - ±45ms 홈런 / ±85ms 안타 / ±130ms 파울 / 그 외 헛스윙
- 별: 클리어 1개, 목표+2 홈런 2개, 목표+4 홈런 3개

## 스테이지 (트롤 투수 10명)

| # | 투수 | 마구 |
|---|---|---|
| 1 | 김정직 | 정직한 직구 |
| 2 | 정지맨 | 공중에서 멈췄다가 더 빠르게 |
| 3 | 뻥카 | 던지는 척 가짜 공 |
| 4 | 거북토끼 | 느리다가 갑자기 총알 |
| 5 | 분신술사 | 셋으로 분신 (진짜만 그림자) |
| 6 | 부메랑 | 되돌아갔다 다시 온다 |
| 7 | 텔레포터 | 사라졌다가 가까이 나타남 |
| 8 | 투명인간 | 그림자만 보임 |
| 9 | 춤신춤왕 | 흔들리며 속도가 변함 |
| 10 | 트롤킹 | 전부 섞어서 |
